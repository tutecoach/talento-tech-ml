# 📦 Recursos, Datos y Documentación

- **`BASE_CONOCIMIENTO.md`**: Enlace y configuración del cuaderno oficial de NotebookLM del curso.
- **`cronograma/`**: Fechas de cursada, horarios y entregas.
- **`datasets/`**: Archivos `.csv`, `.parquet` o scripts de descarga para los ejercicios y el proyecto integrador.
- **`docs/`**: Material complementario, notas teóricas, guías de librerías (`scikit-learn`, `pandas`, `seaborn`) y fórmulas estadísticas.
