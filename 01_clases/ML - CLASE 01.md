## Tu propio modelo de Machine Learning

---

A lo largo del curso, vas a construir tu propio proyecto de inteligencia artificial. No necesitás programar un modelo desde cero: vas a usar herramientas disponibles en Python para entrenar un modelo que resuelva un problema real.

## Formatos de Datasets

#### Datos estructurados

Información organizada en filas y columnas para facilitar su procesamiento.

#### Compatibilidad

Formatos estándar que funcionan con herramientas de análisis y modelado.

#### Procesamiento

Cada formato requiere técnicas específicas de carga y manipulación.

## Formato CSV

---

## El formato CSV

1

#### Simplicidad

Archivo de texto plano con datos separados por comas.

2

#### Portabilidad

Ligero y compatible con prácticamente cualquier herramienta.

3

#### Versatilidad

Fácil de importar y exportar con Pandas.

## Variaciones del CSV

#### Coma (,)

65%

#### Punto y coma (;)

20%

#### Tabulación

10%

#### Pipe (|)

5%

El gráfico muestra la distribución de los separadores más comunes en archivos CSV. La coma es el más utilizado, seguido por el punto y coma, especialmente en países donde la coma se usa para decimales.

![](https://cdn.gamma.app/5k42ay5jcl12uau/1964523f37674e58a6ba6ca90bbe49c2/optimized/Attached-files-bro.svg)

## Consideraciones del CSV

1

#### Encabezados

Algunos CSV incluyen nombres de columnas en la primera fila.

2

#### Codificación

UTF-8, latin1 u otros formatos según región o sistema de origen.

3

#### Limitaciones

No admite jerarquías o relaciones complejas entre datos.

4

#### Limpieza

Puede requerir ajustes para manejar valores faltantes o inconsistentes.

## Formato XLSX

---

![](https://cdn.gamma.app/5k42ay5jcl12uau/f21a1e32456643c2b1a134e91225507b/optimized/Analysis-bro.svg)

## El formato Excel

1

#### Extensiones

Archivos.xlsx o.xls comunes en entornos empresariales.

2

#### Múltiples hojas

Un solo archivo puede contener varias tablas de datos.

3

#### Funcionalidades

Permite fórmulas, estilos y formatos visuales adicionales.

4

#### Peso

Más pesado que CSV, menos eficiente para grandes volúmenes.

## Trabajando con Excel en Python

#### Importación

Uso de read\_excel() en Pandas para cargar los datos.

#### Selección de hojas

Especificación de sheet\_name para elegir la hoja correcta.

#### Manejo de tipos

Conversión y limpieza de diferentes tipos de datos en una misma hoja.

#### Ajuste de filas

Uso de skiprows para ignorar filas que no son parte del dataset.

## Formato JSON

---

## Formato JSON

#### Estructura jerárquica

Permite representar datos anidados y relaciones complejas entre elementos.

Ejemplo:

```
{
  "producto": "Laptop",
  "precio": 1200,
  "características": [
    "8GB RAM",
    "SSD 256GB"
  ]
}
```

#### Ventajas para ML

- Flexible para datos complejos
- Estándar en APIs web
- Fácil manipulación con Python

Para Machine Learning, generalmente necesitamos "aplanar" la estructura jerárquica antes de procesarla.
