# 📚 Clases y Prácticas - Machine Learning

Organiza en esta carpeta el material correspondiente a cada una de las clases del curso.

## Estructura sugerida por clase

Para cada clase se puede crear una subcarpeta (por ejemplo: `clase_01_introduccion/`, `clase_02_eda/`, etc.) conteniendo:
- **`notebook.ipynb`**: Cuaderno práctico con el código desarrollado.
- **`notas.md`**: Apuntes clave, dudas a consultar con los tutores y conceptos destacados.
- **`ejercicios/`**: Consignas y resoluciones de las tareas de la semana.
